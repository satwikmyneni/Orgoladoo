Ladoo – Premium Organic Seed-Based Ladoos

Live Website:
https://organicladoo.netlify.app

Ladoo is a modern organic sweets brand offering handcrafted seed-based ladoos made with natural ingredients, free from refined sugar, and designed for healthy everyday indulgence.

**About the Project**

This website represents the digital storefront for Ladoo Organic Foods.
It is built for:

- Clean brand presentation

- High-performance user experience

- Scalable product management

- SEO-ready organic visibility

- Mobile-first responsiveness

The design reflects a premium, earthy, organic aesthetic aligned with the product category.

**Technology Stack**

The application is built using:

- Vite – Optimized build tooling

- React – Component-based UI architecture

- TypeScript – Strongly typed development

- Tailwind CSS – Utility-driven styling

- shadcn/ui – Structured UI components

- Netlify – Cloud hosting & deployment

This stack ensures fast load times, maintainability, and production scalability.

**Deployment**

The project is deployed via Netlify and accessible at:

https://organicladoo.netlify.app

Publishing updates is managed directly through Lovable’s deployment workflow.

**Domain Configuration**

The project currently runs on a Netlify subdomain.
A custom branded domain can be connected through:

Project → Settings → Domains → Connect Domain
